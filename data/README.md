Here goes a summary of what can be found in each folder:

- `figures/main/` and `figures/supplementary/`: Numerical data used to build the figures in the manuscript and its Supplementary Information (PDF). See also FIGURE_DATA_INDEX.csv for a description
- `ml/`: - data related to the ML development data, exact OOF predictions, screen predictions and model metadata.
- `experimental/Data-Cameron/`: data coming from the high pressure experiments for each liquid (pure or mixture) investigated in our work. These are the sigma obtained from the ruby spheres and the corresponding applied pressure.
